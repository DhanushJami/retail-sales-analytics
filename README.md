# Retail Sales Analytics Dashboard

## Overview
This project is an interactive Power BI dashboard built to analyze retail sales performance, profitability, product trends, and regional insights using a Superstore sales dataset.

## Tools Used
- Power BI
- Python
- Pandas

## Features
- KPI Cards for Total Sales and Total Profit
- Sales Trend Analysis
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Top Products by Sales
- Interactive Slicers and Filtering

## Dataset
Superstore retail sales dataset.

## Key Insights
- Technology category generated the highest sales
- West region showed the strongest performance
- Certain products contributed disproportionately to total revenue
- Sales growth peaked around 2016

## Project Structure
- `/powerbi` → Power BI dashboard file
- `/screenshots` → Dashboard screenshots
- `/data` → Dataset files
